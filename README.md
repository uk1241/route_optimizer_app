# Route Optimizer App

A Flutter app integrating Google Maps to provide real-time navigation and optimized routes for multiple stops with live traffic updates.

## Features
- Real-time GPS location tracking
- Multi-stop route optimization
- Live traffic display
- Turn-by-turn navigation
- Multiple travel modes (drive, walk, cycle)

## Setup
1. Clone the repo.
2. Add your Google Maps API key in `main.dart` and `AndroidManifest.xml`.
3. Run:
   ```bash
   flutter pub get
   flutter run
